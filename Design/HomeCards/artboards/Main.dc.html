Card grammar

Home is a triage surface: four columns, one question each, answered by scanning down. The scan unit is the column, not the card — so every card in every panel puts its attention signal, its identity token, its title and its age in the same place. Panel-specific fields vary; the skeleton never does.

Terminal bridge drops the first prompt submitted after a cold launch
1 Attention dot 6pt, fixed leading x. The only coloured channel on the card, and it always means the same thing: is this moving, stalled, or waiting on you. Sessions already work this way — tickets and MRs adopt it.
2 Identity Monospaced, 10pt secondary. SCRUM-19, !5, or the session's state label. Tabular and stable so the column reads as a ruler, not ragged text.
3 State Tinted text, never a filled capsule. Filled capsules are reserved for artifact chips, which mean linked object, not workflow state.
4 Age Relative, right-aligned, tabular numerals, tertiary. One time language across all four panels — 38m, 4h, 2d. Never an absolute timestamp on a card.
5 Title + action slot 13pt medium — the one element with real size. Fixed x-origin, wraps to two lines only when it needs them. A permanently reserved 16pt trailing slot holds the secondary action, so it can never sit on top of another field.
